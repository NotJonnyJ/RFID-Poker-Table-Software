### RFID Poker Table Control Software

## Install
1. Navigate to git repo
2. create venv 
```powershell
python -m venv .venv
```
3. activate venv
```powershell
.\venv\Scripts\activate.ps1
```
4. If power shell blocks:
```
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```
5. Install packages
```
.\.venv\Script\python.exe -m pip install -r requirements.txt
```

6. Double click executable
